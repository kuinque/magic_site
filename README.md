# Многостраничный сайт с горизонтальным меню-баром

Учебный многостраничный сайт на чистых **HTML / CSS / JavaScript**. Главная фишка — общий горизонтальный навбар сверху, объединяющий все страницы.

## Страницы

| Файл           | Раздел   |
| -------------- | -------- |
| `index.html`   | Главная  |
| `about.html`   | О шоу    |
| `events.html`  | События  |
| `merch.html`   | Мерч     |
| `media.html`   | Медиа    |
| `reviews.html` | Отзывы   |

## Меню-бар

- Sticky-навбар сверху на каждой странице, со ссылками-пилюлями.
- Активная страница автоматически подсвечивается (JS определяет по `location.pathname`).
- Hover-эффект: ссылка получает белую заливку и слегка приподнимается.
- При скролле у навбара появляется лёгкая тень.

## Адаптивность

- Размеры пилюль и отступов масштабируются через `clamp()`.
- На широких экранах ссылки на одной строке по центру.
- На узких экранах (`max-width: 720px`) навбар прокручивается по горизонтали свайпом — все 6 ссылок остаются в одной строке без переноса. Полоса прокрутки скрыта.

## Локальный запуск

Открой `index.html` напрямую в браузере или подними локальный сервер:

```bash
python3 -m http.server 8080
# http://localhost:8080
```

## Деплой на GitHub Pages

1. Запушь содержимое папки в репозиторий на GitHub:

   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<user>/<repo>.git
   git push -u origin main
   ```

2. В репозитории: **Settings → Pages → Source → `main` / `/ (root)`**.
3. Ссылка вида `https://<user>.github.io/<repo>/` появится через минуту.

В корне лежит пустой файл `.nojekyll`, чтобы GitHub Pages не запускал Jekyll и пути работали без сюрпризов.
