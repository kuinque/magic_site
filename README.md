# ILLUSION — первая версия сайта

Первая версия сайта-визитки для шоу **ILLUSION**.
В этой версии реализован только меню-бар, связывающий все будущие страницы сайта.

Демо: [kuinque.github.io/magic_site](https://kuinque.github.io/magic_site/)
(включается в настройках репозитория: **Settings → Pages → Deploy from branch → `main` / `root`**)

## Страницы

| Файл           | Раздел              |
| -------------- | ------------------- |
| `index.html`   | Главный экран       |
| `about.html`   | О шоу               |
| `events.html`  | Ближайшие события   |
| `merch.html`   | Мерч                |
| `media.html`   | Медиа               |
| `reviews.html` | Отзывы              |

## Меню-бар: идея

Менюбар вдохновлён референсом с шоу (тёмный фон + овальный pill-логотип
по центру). Что добавлено сверх референса:

- **Floating glass-pill** — меню парит над контентом, фон с размытием
  (`backdrop-filter`), мягкая тень. Под магический стиль шоу.
- **ILLUSION-логотип по центру** — выступает кнопкой возврата на главную.
- **Подсветка активной ссылки** — JS читает `location.pathname` и
  автоматически помечает текущую страницу.
- **Hover-анимация подчёркивания** с лёгким свечением.
- **Shimmer-эффект** на главном заголовке (под "иллюзорный" стиль).

## Адаптивность

Три брейкпоинта:

| Ширина экрана | Поведение                                                      |
| ------------- | -------------------------------------------------------------- |
| `> 960px`     | Все 5 ссылок + центральный pill-логотип                        |
| `720–960px`   | Уменьшаем отступы и шрифты, всё ещё в одну строку              |
| `≤ 720px`     | Ссылки прячутся, появляется бургер → полноэкранный оверлей-меню |

Дополнительно:

- `prefers-reduced-motion` — отключает анимации для пользователей с
  соответствующей настройкой.
- Скролл фона блокируется, пока открыто мобильное меню.
- Закрытие меню по `Esc` и по клику на пункт.
- ARIA-атрибуты (`aria-expanded`, `aria-controls`, `aria-current`) для
  доступности.

## Запуск локально

Чтобы открыть локально достаточно открыть `index.html` в браузере.
Лучше через простой HTTP-сервер:

```bash
python3 -m http.server 8080
```

И перейти на <http://localhost:8080/>.

## Деплой на GitHub Pages

1. Запушить ветку `main` в `kuinque/magic_site`.
2. **Settings → Pages → Source** → `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Подождать сборку — сайт станет доступен по адресу `https://kuinque.github.io/magic_site/`.

Файл `.nojekyll` в корне уже отключает обработку Jekyll, так что папка
`assets/` подхватится без сюрпризов.
