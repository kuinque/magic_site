# ORANGE WAVE

Многостраничный сайт-визитка вымышленного независимого музыкального шоу. Сверстан на чистых **HTML / CSS / JavaScript** — без сборщиков и фреймворков, чтобы можно было сразу хостить на **GitHub Pages**.

Идея и стиль навбара взяты из задания: пилюли «Меню / ? / Связаться» сверху + анимированное полноэкранное оверлей-меню.

## Особенности меню-бара

- **Пилюли в навбаре.** Те же три кнопки, что в задании: «Меню», «?», «Связаться». На каждой странице.
- **Полноэкранный оверлей** с круговым `clip-path` — раскрывается из угла кнопки «Меню».
- **Stagger-анимация** пунктов: появляются по очереди с задержкой.
- **Большая типографика** (Fraunces, до 128 px) для пунктов меню.
- **Активная страница** подсвечивается белым кружком и кремовым цветом.
- **Hover-эффект:** пункт сдвигается вправо, появляется стрелка `→`.
- **Кнопка «?»** — показывает подсказку-тултип, как пользоваться сайтом.
- **ESC и клик по ссылке** — закрывают меню.
- **Тень** у навбара появляется при скролле.

## Адаптивность

CSS использует `clamp()` для размеров (плавно подстраиваются под ширину экрана) + один брейкпойнт `@media (max-width: 720px)`:

- Кнопка «Связаться» на мобиле превращается в стрелку `→`.
- Сетки `about`, `events`, `media` перестраиваются в одну колонку.
- Размеры пилюль уменьшаются, меню становится компактнее.
- `@media (prefers-reduced-motion)` отключает анимации для пользователей с настройками доступности.

## Локальный запуск

Можно открыть `index.html` напрямую в браузере. Или запустить локальный сервер:

```bash
# через python (если установлен)
python3 -m http.server 8080
# затем открой http://localhost:8080
```

## Деплой на GitHub Pages

1. Создай новый репозиторий на GitHub.
2. Запушь содержимое этой папки в ветку `main`:

   ```bash
   git init
   git add .
   git commit -m "Initial commit: ORANGE WAVE multipage site"
   git branch -M main
   git remote add origin https://github.com/<user>/<repo>.git
   git push -u origin main
   ```

3. Перейди в **Settings → Pages** репозитория.
4. В разделе **Source** выбери ветку `main` и папку `/ (root)`. Сохрани.
5. GitHub Pages соберёт сайт и выдаст ссылку вида `https://<user>.github.io/<repo>/`.

Файл `.nojekyll` уже лежит в корне — он отключает обработку Jekyll, чтобы пути работали корректно.

## Что использовано

- HTML5 (semantic-теги: `header`, `nav`, `main`, `section`, `article`, `footer`).
- CSS3: custom properties, `clamp()`, `grid`, `flexbox`, `clip-path`, `@keyframes`, media queries.
- Vanilla JavaScript (без библиотек): toggle меню, активная страница, тултип, скролл-стейт навбара, обработка ESC.
- Шрифты с Google Fonts: **Fraunces** (заголовки) и **Inter** (текст).
